Інструкція для розробників

Підключення

Підключіть styles/tokens.css, потім styles/components.css. Кореневий атрибут data-theme визначає тему. Зберігайте тему та масштаб у налаштуваннях користувача; демо цього не робить.

<link rel="stylesheet" href="styles/tokens.css">
<link rel="stylesheet" href="styles/components.css">
<button class="vt-btn solid" data-role="green">Зберегти вакансію</button>

Значення кольорів не дублювати всередині компонентів. Кнопки, вкладки й цифри використовують один data-role. Синій логотип залишається постійним.

Модель даних

Vacancy: id, title, company, sourceUrl, sourceName, locationLabel, workMode, salaryMin, salaryMax, currency, salaryPeriod, taxBasis, firstSeenAt, lastSeenAt, status, nextActionAt, matchResult. Невідомі значення передавати як null.

MatchResult: value, denominator, method, matchedSkills, missingSkills, modelVersion, calculatedAt. Джерело знаменника описати у вмісті вкладки «Збіг». Прямий перенос Fit 38 у «38%» заборонений.

SourceRun: sourceId, state, lastSuccessAt, lastAttemptAt, newCount, updatedCount, errorCode, readableReason. Якщо синхронізація не вдалась, не замінювати останні відомі значення нулями.

Асинхронні дії

Початок: відключити повторний запит, показати текст процесу. Успіх: оновити модель та лічильники після відповіді сервера. Помилка: повернути попередній стан, показати причину та повтор. Якщо застосовано optimistic update, потрібен rollback.

Генерація AI: явно показати вакансію, базове резюме, шаблон і провайдера. Документ позначити чернеткою; зберігати версії та автора правок. Жодного автоматичного надсилання відгуку від кнопки генерації.

Імпорт: parse → validate → preview changes → confirm → apply → report. Показати конфлікти ID, відхилені рядки й збережені ручні правки. Експорт CSV/XLSX має нейтралізувати формули в текстових полях.

Навігація та адаптивність

Межа перестроювання 1000 px. На вузькому екрані всі дії доступні в потоці документа; таблиці мають власну горизонтальну область. Не задавати fixed height для текстових блоків. Довгі назви переносяться; критичні дані не обрізаються.

Фільтри та вибрану вакансію зберігати в URL або стані маршруту. Повернення з документа відновлює фільтри й позицію. Віртуалізацію списку застосовувати тільки після профілювання та перевірки клавіатурної доступності.

Відмінності демо і продукту

Реалізовані в демо: навігація, теми, вкладки, пошук, фільтр, локальне збереження в пам’яті сторінки, дошка/таблиця, додавання навички, перевірка розміру/розширення резюме, приклад експорту JSON.

Показані композиційно: робота з поштою, реальне оновлення джерел, додавання/редагування профілів, імпорт, видалення, AI, серверне збереження. Ці кнопки повідомляють, що з’єднання відсутнє. Не використовувати demo.js як production data layer.
