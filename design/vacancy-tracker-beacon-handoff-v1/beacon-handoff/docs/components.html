Специфікація компонентів

Нормативний контракт для реалізації. HTML-бібліотека демонструє базові стилі, але не замінює production-логіку станів.

1. Button

Параметри: role, variant, disabled, busy

Стани: default / hover / focus / active / loading / disabled

44 px min; після успіху зберегти назву дії або додати ✓; повторний запит блокувати

2. Input

Параметри: label, hint, error, value

Стани: empty / filled / focused / invalid / disabled

Помилка пов’язана через aria-describedby; текст не втрачати

3. Tabs

Параметри: items, selectedId, role per item

Стани: selected / idle / focus

Стрілки, Home/End; roving tabindex; панель позначена aria-labelledby

4. JobRow

Параметри: id, title, company, location, match

Стани: new / selected / saved / dismissed

Справжня кнопка; aria-pressed; пояснення збігу не в tooltip

5. Inspector

Параметри: vacancy, selectedTab, documents

Стани: loading / ready / missing / error

Без overlay; зберігати контекст списку; не переносити фокус при звичайному виборі

6. Metric

Параметри: value, unit, role, updatedAt

Стани: ready / stale / missing / loading

Табличні цифри; невідоме = текст; колір за семантикою

7. Table

Параметри: columns, rows, sort, page

Стани: ready / empty / loading / error

th scope; aria-sort; числові колонки праворуч; не інтерактивний tr без клавіатури

8. Status

Параметри: label, kind, detail, timestamp

Стани: ok / delayed / error / offline

Текст + символ; час останнього успіху зберігається

9. Notice

Параметри: kind, message, action

Стани: info / warning / error / success

Критична інформація лишається видимою; aria-live без повторного спаму

10. FileUpload

Параметри: accept, maxSize, onValidate

Стани: idle / validating / invalid / ready

Клієнтська перевірка не замінює серверну; 5 МБ для резюме

11. Dialog

Параметри: title, body, confirm, cancel

Стани: open / submitting / error

Фокус усередині, Escape, повернення до тригера; застосувати native dialog або перевірену реалізацію

12. Pagination

Параметри: page, total, pageSize

Стани: first / middle / last / loading

Видима кількість записів; після зміни сторінки оголосити діапазон
